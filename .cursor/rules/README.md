# Cursor 项目规则

AI 聊天对话系统的完整开发规范。

## 📁 规则文件组织

| 文件 | 说明 |
|------|------|
| `00-overview.md` | 项目概述和技术栈 |
| `01-common.md` | 通用开发规范（前后端共同遵守） |
| `02-backend.md` | 后端开发规范 (Python/FastAPI) |
| `03-frontend.md` | 前端开发规范 (React/TypeScript) |
| `04-references.md` | 参考资源和文档链接 |

## 🚀 使用方式

Cursor 会自动读取 `.cursor/rules/` 目录下的所有规则文件，并应用到项目中。

## 📝 更新规则

直接编辑对应的 `.md` 文件，Cursor 会自动重新加载。
