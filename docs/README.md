```

├── features/           # 功能特性文档
│   ├── rag/           # RAG 相关文档
│   ├── text-to-sql/   # Text-to-SQL 相关文档
│   ├── robot/         # 机器人功能文档

│   ├── api/           # API 文档
│   └── contributing/  # 贡献指南

```

## 📝 文档规范

1. **文档命名**：使用小写字母和连字符，如 `quick-start.md`
2. **文档结构**：每个文档应包含标题、目录、正文和相关链接
3. **更新频率**：功能文档随功能更新，指南文档定期审查
4. **归档规则**：过时或不再维护的文档移至 `archived/` 目录
