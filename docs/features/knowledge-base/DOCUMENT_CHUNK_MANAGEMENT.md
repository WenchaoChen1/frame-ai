# 文档分块管理功能

## 📋 功能概述

模仿 Dify 的文档分块管理系统，提供完整的文档管理和分块查看功能。

## ✨ 新增功能

### 1. **文档列表增强**

#### 搜索和筛选
- **状态筛选**: All Status / 已完成 / 处理中 / 失败 / 待处理
- **文件名搜索**: 实时搜索过滤文档
- **响应式表格**: 自适应布局，支持横向滚动

#### 表格列优化
- **文件名**: 点击可直接查看分块详情（带图标）
- **分段模式**: 显示文档的分块模式（默认"总是"）
- **字符数**: 智能显示（超过1000显示为"k"格式，如 569.6k）
- **召回次数**: 显示文档被召回的次数（当前为0）
- **上传时间**: 格式化的本地时间
- **状态**: 彩色标签，已完成状态带✓图标
- **操作**: 查看分块、删除按钮

### 2. **文档分块查看**

#### 打开方式
- 点击文件名
- 点击"查看分块"按钮

#### 分块弹窗内容
- **文档信息摘要**:
  - 文件类型
  - 文件大小
  - 分块数量
  - 字符数
  - 状态
  - 上传时间

- **分块列表**:
  - 块序号标签
  - 字符数统计
  - 创建时间
  - 分块内容（带展开/收起功能）
  - 分页显示（每页5个分块）

#### 分块内容展示
- 灰色背景高亮显示
- 保留原文格式（换行、空格）
- 默认显示4行，可展开查看全部
- 支持文本选择和复制

### 3. **UI/UX 改进**

#### Dify 风格设计
- 顶部提示框：说明文档功能
- 清晰的筛选和搜索区域
- 现代化的表格设计
- 优雅的分块查看弹窗

#### 交互优化
- 实时搜索过滤
- 加载状态提示
- 空状态友好提示
- 操作反馈消息

## 🔧 技术实现

### 后端 API

#### 新增接口
```
GET /api/knowledge-bases/documents/{doc_id}/chunks
```

**响应格式**:
```json
{
  "total": 10,
  "chunks": [
    {
      "id": 1,
      "chunk_index": 0,
      "content": "文档内容...",
      "character_count": 500,
      "metadata": null,
      "created_at": "2025-10-17T10:00:00"
    }
  ]
}
```

### 前端实现

#### 新增 Service
- `getDocumentChunks(docId)`: 获取文档分块列表

#### 新增 State
- `filteredDocuments`: 过滤后的文档列表
- `searchText`: 搜索关键词
- `statusFilter`: 状态筛选
- `chunksModalVisible`: 分块弹窗可见性
- `selectedDocument`: 选中的文档
- `chunks`: 分块列表
- `chunksLoading`: 分块加载状态

#### 核心功能
- `loadDocumentChunks()`: 加载文档分块
- `openChunksModal()`: 打开分块查看弹窗
- 实时搜索和筛选（useEffect）

## 🎯 使用场景

### 1. 查看文档处理结果
- 检查文档是否正确分块
- 验证分块内容质量
- 调试分块策略

### 2. 文档管理
- 搜索特定文档
- 按状态筛选文档
- 快速定位问题文档

### 3. 内容审查
- 查看每个分块的具体内容
- 确认知识库数据准确性
- 优化文档质量

## 🔍 搜索和筛选规则

### 状态筛选
- **All Status**: 显示所有文档
- **已完成**: 只显示处理完成的文档
- **处理中**: 只显示正在处理的文档
- **失败**: 只显示处理失败的文档
- **待处理**: 只显示等待处理的文档

### 文件名搜索
- 不区分大小写
- 支持部分匹配
- 实时过滤结果
- 可清除搜索

## 💡 最佳实践

### 1. 分块质量检查
1. 上传文档后，点击文件名查看分块
2. 检查分块边界是否合理
3. 确认没有截断重要内容
4. 如有问题，调整分块参数后重新上传

### 2. 文档管理流程
1. 使用状态筛选定位问题文档
2. 使用搜索快速找到特定文档
3. 定期检查失败文档并重新处理
4. 删除无用或质量差的文档

### 3. 性能优化
- 分块列表采用分页加载（每页5个）
- 文档列表支持分页（每页10个）
- 搜索和筛选在前端实时处理
- Modal 关闭时清理状态

## 📝 注意事项

1. **分块数量**: 大文件可能产生大量分块，加载可能需要时间
2. **内容展示**: 默认显示4行，点击"展开更多"查看完整内容
3. **搜索性能**: 文档数量多时，建议使用筛选配合搜索
4. **状态更新**: 文档处理状态会自动更新，可点击刷新按钮

## 🐛 故障排除

### 问题1: 分块列表为空
**原因**: 文档还在处理中或处理失败
**解决**: 检查文档状态，等待处理完成或重新上传

### 问题2: 搜索无结果
**原因**: 搜索关键词不匹配或状态筛选过严
**解决**: 清除搜索词，选择"All Status"重试

### 问题3: 分块内容显示不全
**原因**: 默认折叠显示
**解决**: 点击"展开更多"查看完整内容
