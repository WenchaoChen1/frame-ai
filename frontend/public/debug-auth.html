📝 控制台命令

在浏览器控制台执行以下命令进行调试：

// 查看 token
console.log('Token:', localStorage.getItem('token'));

// 查看用户信息
console.log('User:', JSON.parse(localStorage.getItem('user') || 'null'));

// 清除认证
localStorage.removeItem('token');
localStorage.removeItem('user');
location.reload();
